Approach
A deterministic evidence resolver

Clear only what you can prove.

DIFFERENT_ENTITY

Clear only on a contradiction in a cited record.

SAME_ENTITY

Confirm only when facts agree and nothing contradicts.

REVIEW

Everything else goes to a human. Errors fail closed.

Three rules, built into the code. Clear only on a hard contradiction (date of birth, timeline, location, verified name, entity type, death) backed by a record we cite. Confirm only when the facts agree. Everything else goes to review, and any error falls back to review. The pipeline: resolve which customer was screened, build their verified facts (approved checks beat declared data), build the listed person's facts, then decide. Plain Python, no model, no network. (≈25 s)
